# Visual selection and RAS diagram grammar

Use a visual only when it communicates information better than prose or a
table. Selection order is user asset, data-derived chart or original RAS
diagram, authorized generated illustration, licensed sourced image, then omit.

The built-in diagram grammar uses the resolved theme's semantic color/typography tokens, explicit
node hierarchy, orthogonal connectors, attachment points, a complexity budget,
and accessible title/caption/alternative text. Diagram families are flow,
hierarchy, timeline, lifecycle, architecture, relationship, comparison,
matrix, process, and cause/effect. The same specification emits SVG and PNG.
Visuals must not imply data absent from the source ledger.

Charts and diagrams are rendered as branded cards with theme-specific palette,
grid, node, connector, label, and typography tokens. The same visual spec is
kept in the canonical model and emitted as SVG plus PNG for PDF and DOCX.
