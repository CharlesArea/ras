# Branding

Brand resolution is explicit profile, project `.ras/brand.yaml`, then the
neutral built-in profile. A brand overlays the selected theme pack rather than
removing its layout intent. Profiles use semantic roles: paper, surface, ink,
muted, rule, accent, positive, warning, negative; heading/body/mono/CJK
fallback fonts; logo/attribution; and spacing, table, chart, and diagram
tokens. Contrast and font availability are checked. Missing optional values
fall back to neutral defaults. The resolved brand and theme are recorded in
the build and QA receipts.
